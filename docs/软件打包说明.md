# 软件打包说明

本文档用于把当前项目打包成 Windows 桌面软件。前端位于 `frontend` 目录，技术栈为 Electron + React + Vite，打包工具为 `electron-builder`。

## 1. 打包前准备

请先确认项目根目录下存在这些内容：

```text
ffmpeg\bin\ffmpeg.exe
ffmpeg\bin\ffprobe.exe
frontend\package.json
requirements.txt
main.py
```

首次打包前安装前端依赖：

```powershell
cd .\frontend
npm install
```

如果本机没有准备过 Python 虚拟环境，打包脚本会自动调用 `setup_venv.ps1` 创建 `.venv`，并生成 `portable-python` 运行时。

## 2. 生成安装包

在项目根目录执行：

```powershell
cd .\frontend
$env:ELECTRON_RUN_AS_NODE = $null
npm run dist
```

该命令会执行以下流程：

1. 检查 `ffmpeg.exe` 和 `ffprobe.exe` 是否存在。
2. 构建或复用 `portable-python`。
3. 执行前端构建：`npm run build`。
4. 使用 `electron-builder` 生成 Windows 安装包。

生成结果：

```text
frontend\release\Clone Narration Studio-Setup-1.0.0.exe
```

把这个 `.exe` 发给用户即可安装。

## 3. 生成免安装目录版

如果只想生成可直接运行的目录版，执行：

```powershell
cd .\frontend
$env:ELECTRON_RUN_AS_NODE = $null
npm run pack:dir
```

生成结果：

```text
frontend\release\win-unpacked\Clone Narration Studio.exe
```

发布目录版时，需要把整个 `win-unpacked` 文件夹一起打包发送，不能只发送里面的 exe。

## 4. 打包内容

安装包会包含：

- 前端构建产物：`frontend\dist`
- Electron 主进程文件：`frontend\electron`
- 后端 Python 脚本与模块
- `portable-python` 运行时
- `ffmpeg\bin` 下的 `ffmpeg.exe`、`ffprobe.exe`、`ffplay.exe`

最终安装包体积会比较大，属于正常情况。

## 5. 常见问题

### 缺少 ffmpeg

如果出现 `missing bundled ffmpeg`，请确认：

```text
ffmpeg\bin\ffmpeg.exe
ffmpeg\bin\ffprobe.exe
```

这两个文件存在。

### Electron 下载慢或失败

脚本默认使用国内镜像：

```powershell
$env:ELECTRON_BUILDER_BINARIES_MIRROR = "https://npmmirror.com/mirrors/electron-builder-binaries/"
```

如果网络仍然失败，可以重新执行 `npm run dist`。

### portable-python 构建慢

首次打包会复制 Python 运行时和依赖，还会安装 PyTorch，耗时较长。后续如果 `portable-python\.runtime-ready` 存在且配置未变化，会优先复用已有运行时。

### 重新干净打包

如需重新生成运行时和安装包，可以手动删除：

```text
portable-python
frontend\release
```

然后重新执行：

```powershell
cd .\frontend
npm run dist
```
