# 画面定位当前实现逻辑

本文档记录当前 `4_visual_alignment_engine` 的实际实现。生产入口只保留：

```text
4_visual_alignment_engine/run.py
4_visual_alignment_engine/run_shot_match_localize.py
```

当前算法版本：

```text
shot_match_localize_orb_v1
```

## 1. 模块目标

第 4 步把第 1 步参考视频里的 `ref_shots` 定位到第 3 步原电影里的 `movie_shots`，输出下游继续使用的：

```text
outputs/4_visual_alignment_engine/ref_to_movie_timeline.json
```

下游仍然读取这些字段：

- `ref_shot_id`
- `ref_start`
- `ref_end`
- `movie_start`
- `movie_end`
- `movie_shot_ids`
- `match_score`
- `final_score`
- `match_type`
- `confidence`
- `status`
- `diagnostics`
- `candidates`

## 2. 输入

必需输入：

```text
--ref-analysis outputs/1_reference_analyzer/ref_analysis.json
--movie-shots outputs/3_movie_shot_parser/movie_shots.json
```

默认会从这两个 JSON 的同级目录自动推导镜头片段目录：

```text
outputs/1_reference_analyzer/shot_clips
outputs/3_movie_shot_parser/shot_clips
```

也可以显式指定：

```text
--reference-dir path/to/reference/shot_clips
--movie-dir path/to/movie/shot_clips
```

片段文件名必须和 shot id 对齐，例如：

```text
ref_shot_001.mp4
movie_shot_000001.mp4
```

第 1 步和第 3 步当前默认会导出这些片段，所以主流水线不需要额外参数。

## 3. 核心流程

1. 读取 `ref_shots` 和 `movie_shots`，按 `start` 排序。
2. 按 `ref_shot_id` / `movie_shot_id` 在 `shot_clips` 目录找对应视频片段。
3. 对每个存在视频文件的参考片段采样多帧，默认 `--sample-count 6`、`--frame-size 384`。
4. 每帧生成轻量描述子：
   - 去掉底部字幕高发区域。
   - 提取整体灰度结构。
   - 提取中心区域灰度结构。
   - 提取 HSV 颜色直方图。
5. 同时提取 ORB 局部特征，建立哈希候选索引；弱匹配会尝试 FLANN ANN 补召回。
6. 使用全局相似度、局部召回、帧级精分和时长比组成候选集。
7. 对候选镜头执行单应性几何验证，并利用相邻参考镜头提供有限的序列支持。
8. `run.py` 把定位结果中的电影镜头索引映射回 `movie_shot_id/start/end`。
9. 生成 timeline、诊断报告和人工复核素材。

## 4. 常用参数

```text
--sample-count 6
--frame-size 384
--workers 4
--neighbor-radius 2
--candidate-count 30
--min-score 0.35
--min-geometry-inliers 20
--top-k 3
--manual-overrides overrides.json
--diagnostics-dir outputs/4_visual_alignment_engine/diagnostics
```

兼容旧调用的参数仍会被 argparse 接收，例如 `--keyframes-per-shot`、`--recall-top-k`、`--alignment-mode`、`--feature-mode`、`--disable-global-path`。其中 `--keyframes-per-shot` 是 `--sample-count` 的别名，`--recall-top-k` 是 `--candidate-count` 的别名，其余旧参数仅保留兼容。

## 5. 输出

主输出：

```text
outputs/4_visual_alignment_engine/ref_to_movie_timeline.json
```

人工复核输出：

```text
outputs/4_visual_alignment_engine/matches.csv
outputs/4_visual_alignment_engine/matches.json
outputs/4_visual_alignment_engine/pairs/
outputs/4_visual_alignment_engine/low_confidence_pairs/
outputs/4_visual_alignment_engine/diagnostics/low_confidence_report.json
```

`pairs/` 中每个目录包含：

```text
reference.mp4
movie.mp4
match.json
```

低分或低置信度结果会额外复制到 `low_confidence_pairs/`。

## 6. 状态与置信度

可接受状态：

```text
matched
matched_low_confidence
```

其他常见状态：

```text
needs_review
missing_reference_clip
unmatched
```

置信度由匹配分数、候选分差和路径连续性共同决定：

- `high`：分数较高、候选分差足够、路径连续。
- `medium`：分数可用，或路径连续性较好。
- `low`：需要人工检查。

## 7. 人工覆写

覆写文件格式：

```json
{
  "overrides": [
    {
      "ref_shot_id": "ref_shot_001",
      "movie_shot_id": "movie_shot_000123"
    }
  ]
}
```

运行时传入：

```text
--manual-overrides overrides.json
```

有效覆写会把该参考镜头状态置为 `matched`，`match_type` 置为 `manual_override`。

