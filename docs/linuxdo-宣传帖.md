# 【分享】做了一个影视解说克隆工具：参考一条解说视频，自动对齐原片画面并生成剪映草稿 / MP4

最近在折腾一个面向影视解说二创的桌面工具，叫 **Clone Narration Studio / 影视解说克隆软件**。

它的目标很简单：把“参考解说视频 -> 原片素材 -> 新解说成片”这条流程尽量自动化，减少手工找镜头、切段、对齐、写草稿、进剪映排时间线的重复劳动。

目前已经能跑通一条比较完整的本地流水线，适合做影视解说工作流研究、二创流程自动化测试，或者给剪辑团队做半自动化生产辅助。

## 它能做什么

你准备这些素材：

- 一条参考解说视频
- 对应原片视频
- 参考视频字幕，推荐提供 SRT，速度更快
- 原片字幕，可选，提供后原声判断和画面绑定会更稳
- 一个 OpenAI 兼容接口 Key，用于文案仿写 / 改写

软件会自动完成：

1. 解析参考解说视频的字幕、镜头、节奏。
2. 把参考解说切成语义段落。
3. 拆分原片镜头。
4. 按参考视频画面去原片里找对应镜头。
5. 绑定“每段解说应该配哪段画面”。
6. 补充原片字幕信息，用于判断人物对白、原声片段等。
7. 调用 AI 生成新的解说文案。
8. 生成新视频时间线。
9. 输出剪映 / CapCut 草稿，或者直接渲染成 MP4。

简单说，就是把以前大量靠人工拖时间线、找画面、对字幕的活，拆成一条可复用的自动流水线。

## 两种主要玩法

### 1. 完整仿稿生成

适合想参考某条爆款解说的结构和节奏，重新生成一条新解说内容的场景。

流程大概是：

```text
参考视频解析 -> 解说切段 -> 原片镜头拆分 -> 画面定位 -> 文案仿写 -> 时间线生成 -> 剪映草稿 / MP4
```

这个模式会调用 AI 改写文案，也可以配合 TTS 生成解说音频。

### 2. 参考音频画面重组

这个分支比较轻量：复用参考视频里的原音频，只把画面替换成定位到的原片画面。

流程大概是：

```text
参考视频解析 -> 原片镜头拆分 -> 画面定位 -> 重组时间线 -> 剪映草稿 / MP4
```

它不需要走文案切分、仿写、TTS 那套完整链路，适合先验证“画面定位”和“时间线重建”的效果。

## 桌面端

项目带了一个 Electron + React + Vite 做的 Windows 桌面界面。

界面里可以配置素材路径、选择运行模式、启动生成任务，并实时查看后端流水线日志。底层后端是 Python，主要负责视频分析、镜头拆分、画面对齐、时间线生成和最终导出。

打包后是 Windows 安装包，也可以生成免安装目录版。

## 输出结果

当前支持这些输出：

- 剪映 / CapCut 草稿
- 直接渲染 MP4
- 各步骤中间 JSON，例如镜头拆分结果、画面匹配结果、最终时间线
- 音频片段、镜头 breakdown 等调试产物

如果选择生成剪映草稿，软件会尝试自动写入本机剪映 / CapCut 的草稿目录；也可以手动指定草稿目录。

## 运行环境

主要环境：

- Windows
- Python 后端
- Electron 桌面端
- ffmpeg
- PyTorch / CUDA 可选
- OpenAI 兼容接口，用于第 6 步文案改写

有 GPU 会更舒服，尤其是镜头分析这类步骤；没有 GPU 也可以走 CPU，只是速度会慢一些。

RTX 50 系列机器建议使用 `cu128` 的 PyTorch wheel。

## 当前限制

先说清楚，这不是“点一下就稳定量产爆款”的黑盒神器，更像是一个把影视解说生产拆成可控流水线的自动化工具。

目前比较适合愿意折腾一点素材、字幕、模型和参数的人。

已知限制：

- Windows 体验最完整。
- 文案仿写依赖 OpenAI 兼容接口，没有 Key 会在第 6 步失败。
- 素材质量、字幕质量、参考视频剪辑方式会明显影响最终效果。
- 当前更偏“辅助剪辑”和“工作流自动化”，不是完全替代人工审片和精修。
- 首次打包 / 首次运行依赖安装会比较久，尤其是 PyTorch 和 portable-python。

## 我为什么做这个

影视解说的很多工作其实不是创作本身，而是机械劳动：

- 反复看参考视频
- 把文案拆成段
- 去原片里找对应镜头
- 对时间线
- 判断哪些地方保留原声
- 把素材拖进剪映再排一遍

这些步骤非常耗时间，而且每条视频都在重复。

所以我想把它做成一套可复用的流水线：创作者负责判断、选题和最终审美，机器负责把能自动化的部分先跑出来。

## 适合谁

可能适合：

- 做影视解说、混剪、二创内容的人
- 想研究视频自动剪辑流水线的人
- 想把剪映草稿生成接到自己工作流里的人
- 对镜头匹配、字幕对齐、AI 改写、视频时间线生成感兴趣的人

不太适合：

- 完全不想配置环境的人
- 期待上传一个视频就 100% 自动出完美成片的人
- 对影视二创版权风险没有基本判断的人
