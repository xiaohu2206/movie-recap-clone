佬友们好，今天来分享一个最近在折腾的桌面工具：**Clone Narration Studio / 影视解说克隆软件**。

不知道有没有做影视解说、混剪、二创的佬友和我一样痛苦过：

- 看了一条参考解说视频，觉得结构、节奏、转场都不错，想基于另一部片子复刻一版。

- 手动扒字幕、拆文案、找原片镜头，一段一段拖进剪映排时间线。

- 原片很长，参考视频又剪得很碎，找对应画面经常找到怀疑人生。

- 有些片段要保留原片对白，有些片段要重新配解说，剪着剪着就乱了。

- 最后还要生成剪映 / CapCut 草稿，或者直接导出 MP4。

能不能搞一个东西，把“参考解说视频 -> 原片素材 -> 新解说成片”这条链路尽量自动化？

于是我搓了一个 **影视解说克隆工具**。

它不是那种“上传一个视频，点一下，稳定量产爆款”的黑盒神器，更像是一个把影视解说生产拆成可控流水线的辅助工具：机器先把能自动化的部分跑出来，创作者再负责判断、选题、审美和最后精修。

简单说，它现在主要做这件事：

参考一条解说视频，自动解析字幕、镜头和节奏，到原片里找对应画面，再生成新视频时间线，最后输出剪映 / CapCut 草稿或 MP4。

## 它能做什么

你准备这些素材：

- 一条参考解说视频。

- 对应的原片视频。

- 参考视频字幕，推荐提供 SRT，速度更快。

- 原片字幕，可选，提供后原声判断和画面绑定会更稳。

- 一个 OpenAI 兼容接口 Key，用于文案仿写 / 改写。

软件会尝试自动完成：

1. 解析参考解说视频的字幕、镜头和节奏。

2. 把参考解说切成语义段落。

3. 拆分原片镜头。

4. 按参考视频画面去原片里找对应镜头。

5. 绑定“每段解说应该配哪段画面”。

6. 补充原片字幕信息，用于判断人物对白、原声片段等。

7. 调用 AI 生成新的解说文案。

8. 生成新视频时间线。

9. 输出剪映 / CapCut 草稿，或者直接渲染成 MP4。

以前大量靠人工拖时间线、找画面、对字幕的活，现在可以先拆成一条可重复运行的流水线。

## 两种主要玩法

### 1. 完整仿稿生成

适合想参考某条解说视频的结构和节奏，重新生成一条新解说内容的场景。

流程大概是：

```text

参考视频解析 -> 解说切段 -> 原片镜头拆分 -> 画面定位 -> 文案仿写 -> 时间线生成 -> 剪映草稿 / MP4

```

这个模式会调用 AI 改写文案，也可以配合 TTS 生成解说音频。

### 2. 参考音频画面重组

这个分支比较轻量：复用参考视频里的原音频，只把画面替换成定位到的原片画面。

流程大概是：

```text

参考视频解析 -> 原片镜头拆分 -> 画面定位 -> 重组时间线 -> 剪映草稿 / MP4

```

它不需要走文案切分、仿写、TTS 那套完整链路，适合先验证“画面定位”和“时间线重建”的效果。

## 和普通剪辑流程的区别

传统流程里，很多时间不是花在创作本身，而是花在重复劳动上：

- 反复看参考视频。

- 把文案拆成段。

- 去原片里找对应镜头。

- 对时间线。

- 判断哪些地方保留原声。

- 把素材拖进剪映再排一遍。

这个工具的定位不是替代剪辑师，也不是替代创作者的判断，而是把这些机械步骤尽量变成可以反复执行、可以检查中间结果的流水线。

生成出来的剪映草稿可以继续人工精修；如果只是想快速看效果，也可以直接渲染 MP4。

## 输出结果

当前支持这些输出：

- 剪映 / CapCut 草稿。

- 直接渲染 MP4。

- 各步骤中间 JSON，例如镜头拆分结果、画面匹配结果、最终时间线。

- 音频片段、镜头 breakdown 等调试产物。

如果选择生成剪映草稿，软件会尝试自动写入本机剪映 / CapCut 的草稿目录；也可以手动指定草稿目录。

## 运行环境

主要环境：

- Windows。

- Python 后端。

- Electron 桌面端。

- ffmpeg。

- PyTorch / CUDA 可选。

- OpenAI 兼容接口，用于文案仿写 / 改写。

有 GPU 会更舒服，尤其是镜头分析这类步骤；没有 GPU 也可以走 CPU，只是速度会慢一些。

RTX 50 系列机器建议使用 `cu128\` 的 PyTorch wheel。

## 当前限制

先叠甲：这不是“点一下就稳定量产爆款”的工具。

它目前更适合愿意折腾一点素材、字幕、模型和参数的人，尤其适合拿来研究影视解说工作流、剪映草稿生成、视频自动剪辑流水线。

已知限制：

- Windows 体验最完整。

- 文案仿写依赖 OpenAI 兼容接口，没有 Key 会在仿稿步骤失败。

- 素材质量、字幕质量、参考视频剪辑方式会明显影响最终效果。

- 当前更偏“辅助剪辑”和“工作流自动化”，不是完全替代人工审片和精修。

- 首次打包 / 首次运行依赖安装会比较久，尤其是 PyTorch 和 portable-python。

- 影视二创本身有版权风险，建议只在自己有判断、有授权或符合平台规则的范围内使用。
